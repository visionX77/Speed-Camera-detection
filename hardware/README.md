
# VisionX Hardware Development

## Project
AI-Based Vehicle Speed Violation Detection System

## Main Hardware
- Raspberry Pi 5
- Raspberry Pi Camera Module 3
- HLK-LD2450 24GHz mmWave Radar
- Raspberry Pi Cooling Fan
- microSD Card
- 27W USB-C Power Supply

## Main Functions
1. Vehicle detection
2. Vehicle tracking
3. Speed estimation
4. License plate recognition
5. Speed violation recording

## Development Status
Hardware design and component selection in progress.
